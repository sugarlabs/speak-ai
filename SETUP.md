# Setup Guide

This guide helps new contributors set up Speak-AI locally.

---

## Prerequisites

Make sure you have these installed:

- Git
- Python 3.8+
- VS Code (recommended)
- Sugar environment (optional but useful)

---

## 1. Fork the Repository

Go to the main repository and click **Fork**.  
This creates your own copy of the project.

---

## 2. Clone Your Fork

```bash
git clone https://github.com/YOUR-USERNAME/speak-ai.git
cd speak-ai
3. Create a New Branch

Always create a separate branch for changes:

git checkout -b your-feature-name
4. Install Dependencies

Make sure Python dependencies are installed.

Example:

pip install -r requirements.txt

(If requirements.txt is not available, install dependencies manually.)

5. Run the Project

Depending on your environment:

Run inside Sugar desktop, or

Run as a standalone Python activity (if supported)

6. Make Your Changes

You can contribute by:

Improving documentation

Fixing bugs

Adding features

Enhancing UI

Writing tests

7. Commit Your Changes
git add .
git commit -m "Describe your change clearly"
8. Push Your Branch
git push origin your-branch-name
9. Create a Pull Request

Go to GitHub and click:

Compare & Pull Request

Explain:

What you changed

Why it helps

Screenshots (if UI changes)

Tips for Beginners

Start with small contributions

Read existing code before editing

Follow project structure

Be respectful in discussions

Happy contributing 🚀
