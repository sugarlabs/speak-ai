# The default torch wheel on PyPI is the CUDA build, which drags in ~3.4 GB of
# nvidia and triton libraries. Sugar's target hardware has no GPU, so those are
# dead weight on exactly the machines that can least afford it. The CPU wheel
# is smaller and uses less memory at runtime:
#
#   venv      5.4 GB -> 1.7 GB
#   peak RSS  1637 MB -> 1305 MB
#   synthesis 1009 ms -> 1073 ms  (about 6% slower, worth it)
#
# The extra index is what makes pip pick torch-x.y.z+cpu over the plain build.
--extra-index-url https://download.pytorch.org/whl/cpu

torch
numpy
transformers
huggingface_hub
