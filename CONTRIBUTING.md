# Contributing to Speak AI 🤝

Thank you for your interest in contributing!
We welcome contributors of all experience levels, including beginners.

This guide will help you get started with contributing to the project.

---

## 🌟 Ways to Contribute

You can contribute in many ways:

* Improve documentation
* Fix typos or formatting
* Add comments to code
* Improve UI or accessibility
* Fix bugs
* Suggest new features

Even small contributions are valuable!

---

## 🚀 Getting Started

### 1. Fork the Repository

Click the **Fork** button on GitHub to create your own copy.

---

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/speak-ai.git
cd speak-ai
```

---

### 3. Create a Branch

Create a new branch for your changes:

```bash
git checkout -b your-feature-name
```

Use meaningful branch names like:

* fix-readme-format
* add-contributing-guide
* typo-fixes

---

### 4. Make Your Changes

* Keep changes focused and small
* Follow existing code style
* Add comments where helpful

---

### 5. Commit Your Changes

```bash
git add .
git commit -m "Describe your change clearly"
```

Example commit messages:

* Improve README formatting
* Fix typo in documentation
* Add contributing guide

---

### 6. Push to GitHub

```bash
git push origin your-feature-name
```

---

### 7. Open a Pull Request

Go to your fork on GitHub and click **Compare & pull request**.

In your PR:

* Explain what you changed
* Keep the description clear and concise

---

## 🧠 Contribution Tips

* Start with documentation improvements if you're new
* Check existing pull requests to avoid duplicates
* Keep pull requests small and focused
* Be respectful in discussions

---

## 💬 Communication

If you're unsure where to start:

* Open an issue
* Ask a question in discussions
* Explore beginner-friendly issues

We’re happy to help new contributors!

---

## ❤️ Code of Conduct

Please be respectful and inclusive when interacting with others in the community.

---

## 🎉 Thank You!

Your contributions help improve the project and support open-source learning for everyone.

Happy contributing 🚀
